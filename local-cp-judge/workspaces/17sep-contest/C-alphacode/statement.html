Problem C — Alphacode

View on SPOJ

Problem Statement

Alice and Bob communicate using a numerical cipher where the letters of the English alphabet 'A' through 'Z' are encoded as numbers 1 through 26:

'A' → 1, 'B' → 2, ..., 'I' → 9, 'J' → 10, ..., 'Z' → 26.

Given an encoded string of digits, calculate the total number of possible original messages that could have produced this encoding.

The input consists of multiple test cases. The input is terminated by a single line containing 0.

Input Format

Each test case is given on a separate line containing a non-empty string of digits of length up to 5000. The last line of the input contains 0, which should not be processed.

25114
1111111111
3333333333
0

Output Format

For each test case, output the number of possible decodings on a new line.

Constraints

  • String length up to 5000 digits.
  • Answer fits within a 64-bit integer.
  • Input is terminated by 0.

Examples

Example 1 Input 
25114
1111111111
3333333333
0
Example 1 Output 
6
89
1
Explanation: • For 25114, the 6 valid decodings are:
  1. 2 5 1 1 4 → BEAAD
  2. 2 5 1 14 → BEAN
  3. 2 5 11 4 → BEKD
  4. 25 1 1 4 → YAAD
  5. 25 1 14 → YAN
  6. 25 11 4 → YKD
• For 1111111111 (ten 1's): Decodings correspond to Fibonacci F11 = 89.
• For 3333333333: No double-digit '33' is ≤ 26, so only 1 decoding (CCCCCCCCCC) is possible = 1.

Dynamic Programming Breakdown

State Definition: Let dp[i] be the number of decodings for the prefix of length i.

Base Cases: dp[0] = 1, and dp[1] = 1 (assuming s[0] ≠ '0').

Transitions: For each position i ≥ 2:

  • Single digit: If s[i - 1] ≠ '0', the digit forms a valid letter: dp[i] += dp[i - 1]
  • Two digits: If the two-digit number val = int(s[i-2:i]) satisfies 10 ≤ val ≤ 26: dp[i] += dp[i - 2]

Zero Handling: Note that '10' and '20' are valid double digits, but a standalone '0' cannot be parsed. If both single and double digit transitions are invalid, dp[i] remains 0.

Complexity: Time: O(|S|) • Space: O(1) keeping only the last two DP states.
