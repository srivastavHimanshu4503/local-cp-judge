Problem D — Aibohphobia

View on SPOJ

Problem Statement

BuggyD suffers from a severe psychological condition called aibohphobia — the irrational fear of palindromes (words that read the same backwards and forwards). Notice that the name 'aibohphobia' itself is a palindrome!

To help overcome this fear, he wants to transform any given word into a palindrome by inserting characters. You can insert characters at any position (at the beginning, middle, or end).

Given a string S, find the minimum number of character insertions required to make it a palindrome.

Input Format

The first line contains an integer T, the number of test cases. Each of the next T lines contains a single string S.

T
S_1
...
S_T

Output Format

For each test case, print the minimum number of insertions on a new line.

Constraints

  • 1 ≤ T ≤ 100
  • 1 ≤ |S| ≤ 6100
  • S consists of lowercase English letters.

Examples

Example 1 Input 
1
fft
Example 1 Output 
1
Explanation: Given string: "fft".
• Insert 't' at the beginning → "tfft" (a palindrome with 1 insertion).
• Alternatively, insert 't' after the first 'f' → "fttf" (also 1 insertion).
No 0-insertion solution exists since 'fft' is not a palindrome. Minimum insertions = 1.

Dynamic Programming Breakdown

Fundamental Relationship:

The minimum number of insertions to make S a palindrome is equal to:

Min Insertions = |S| - LPS(S)

Where LPS(S) is the Longest Palindromic Subsequence of S. Furthermore, LPS(S) is identical to the Longest Common Subsequence (LCS) between S and its reverse Srev:

LPS(S) = LCS(S, S[::-1])

Space Optimization: Since |S| ≤ 6100, allocating a full 6100 × 6100 integer matrix requires ~150 MB and risks Memory Limit Exceeded (MLE). By maintaining only two rows (current and previous) of length |S|, memory drops to under 50 KB.

Complexity: Time: O(|S|2) • Space: O(|S|).
