Problem A — Alternating Sequences

View on SPOJ

Problem Statement

Given an array a of N non-zero integers (a1, a2, ..., aN), find the length of the longest alternating subsequence.

An alternating sequence b1, b2, ..., bk (k ≥ 1) must satisfy two conditions:

  1. Strictly increasing absolute values: |b1| < |b2| < |b3| < ... < |bk|
  2. Strictly alternating signs: Adjacent elements must have opposite signs. That is, if b1 > 0, then b2 < 0, b3 > 0, and so on (or vice versa).

Input Format

The first line contains a single integer N. The second line contains N space-separated integers a1, a2, ..., aN.

N
a_1 a_2 ... a_N

Output Format

Print a single integer: the length of the longest alternating subsequence.

Constraints

  • 1 ≤ N ≤ 5000
  • |ai| ≤ 109
  • ai ≠ 0

Examples

Example 1 Input 
8
1 2 -2 -3 5 -7 -8 10
Example 1 Output 
5
Explanation: Consider the subsequence [1, -2, 5, -7, 10]:
• Magnitudes: |1| = 1 < |-2| = 2 < |5| = 5 < |-7| = 7 < |10| = 10 (strictly increasing).
• Signs: +1, -2, +5, -7, +10 (alternates: positive, negative, positive, negative, positive).
Length = 5. (Another valid candidate of length 5 is [2, -3, 5, -7, 10]).

Dynamic Programming Breakdown

This problem is a variant of the classic Longest Increasing Subsequence (LIS) problem:

State Definition: Let dp[i] be the length of the longest alternating subsequence ending at index i.

Base Case: Initialize dp[i] = 1 for all i (each individual element forms a valid sequence of length 1).

Transitions: For each index i from 0 to N - 1, examine every preceding index j < i:

if abs(a[j]) < abs(a[i]) and ((a[j] > 0 and a[i] < 0) or (a[j] < 0 and a[i] > 0)):
    dp[i] = max(dp[i], dp[j] + 1)

Complexity: Time: O(N2) • Space: O(N). With N = 5000, 2.5 × 107 iterations comfortably executes within the 2.0s limit.
