Problem A — Rabbit / Frog 1

View on AtCoder

Problem Statement

There are N stones numbered 1, 2, ..., N. For each i (1 ≤ i ≤ N), the height of Stone i is hi.

A frog is initially on Stone 1. It will repeat the following action some number of times to reach Stone N:

  • If the frog is currently on Stone i, jump to Stone i + 1 or Stone i + 2. Here, a cost of |hi − hj| is incurred, where j is the stone to land on.

Find the minimum possible total cost incurred before the frog reaches Stone N.

Input Format

The input is given from Standard Input in the following format:

N
h_1 h_2 ... h_N

Output Format

Print the minimum possible total cost incurred.

Constraints

  • 2 ≤ N ≤ 105
  • 1 ≤ hi ≤ 104
  • All values in input are integers.

Examples

Example 1 Input 
4
10 30 40 20
Example 1 Output 
30
Explanation: Follow the path: Stone 1 → Stone 2 → Stone 4.
• Jump 1 → 2: cost = |10 − 30| = 20.
• Jump 2 → 4: cost = |30 − 20| = 10.
• Total cost = 20 + 10 = 30.
(Taking 1 → 3 → 4 would cost |10 − 40| + |40 − 20| = 30 + 20 = 50).
Example 2 Input 
2
10 10
Example 2 Output 
0
Explanation: With only 2 stones, the frog must jump directly 1 → 2.
Cost = |10 − 10| = 0.
Example 3 Input 
6
30 10 60 10 60 50
Example 3 Output 
40
Explanation: Optimal path: Stone 1 → Stone 3 → Stone 5 → Stone 6.
• 1 → 3: |30 − 60| = 30.
• 3 → 5: |60 − 60| = 0.
• 5 → 6: |60 − 50| = 10.
• Total cost = 30 + 0 + 10 = 40.

Dynamic Programming Breakdown

State Definition: Let dp[i] be the minimum cost to reach Stone i (0-indexed: 0 ≤ i < N).

Base Cases:

  • dp[0] = 0 (starting at Stone 0 has 0 cost)
  • dp[1] = abs(h[1] - h[0]) (can only reach Stone 1 from Stone 0)

Recurrence Relation: For any stone i ≥ 2, we can only arrive from stone i - 1 or stone i - 2:

dp[i] = min(
    dp[i - 1] + abs(h[i] - h[i - 1]),
    dp[i - 2] + abs(h[i] - h[i - 2])
)

Complexity: Time: O(N) • Space: O(N) or O(1) by storing only the last two values.
